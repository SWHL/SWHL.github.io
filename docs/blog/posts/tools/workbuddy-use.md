最近没有了公司给的 CodeX 账号，导致一时手上还没有个趁手的工具了。

经过调研，打算先入手 WorkBuddy 试试，一顿安装后，发现用起来形式和 CodeX 差不多。同时，个别模型还限免。国内用起来还比较舒服。

![](https://raw.githubusercontent.com/SWHL/SWHL.github.io-Assets/main/images/c1/f7/c1f75e382b175c775f00ec0f4ea0f5665083d298d73a23b1b75ca2d37b5b1cf8.png)

同质的工具还有千问工作、豆包工作和 TRAE。先用 WorkBuddy 试试。与其观望，不如下手试试。

WorkBuddy 是积分制的形式，注册就送积分。这积分订阅制基本是腾讯家的拿手好戏了。

后来，我才了解到还有一个 CodeBuddy，专门做代码编写的工具。背后和 WorkBuddy 是同一个账号，但是可选的模型不太多。

WorkBuddy 是日常办公使用，CodeBuddy 是编写代码使用。我觉得可以先用 CodeBuddy，积分不够了，再用 WorkBuddy 的免费模型就行。

 工具不重要，重要的是清楚自己要做什么。
